# Weekend Learning

This is the index of Weekend Learning, my LinkedIn newsletter on how LLM evaluation breaks. Every two weeks it takes one finding, recomputes every number in it from the data, and ends with an hour you can spend running the same check yourself. The index is online at [mohammadi.cv/weekend-learning](https://mohammadi.cv/weekend-learning/), and you can [subscribe on LinkedIn](https://www.linkedin.com/newsletters/weekend-learning-7044258763238731776/).

I'm Hadi Mohammadi. I did my PhD in natural language processing and explainable AI at Utrecht University, and I work on AI and data science in the Netherlands. The rest of my work is at [mohammadi.cv](https://mohammadi.cv).

## How the page is built

`index.html` and the table above are generated from `issues.json`, so don't edit them by hand. Change `issues.json` and run

```sh
python3 build.py
```

It needs Python 3.9 or later and nothing outside the standard library. Running it twice changes nothing. `python3 build.py --check` writes nothing and fails if either file is out of date.

Adding an issue is one entry in `issues.json`:

- `number`, and `date` as YYYY-MM-DD, the day it went out.
- `title` and `linkedin`, character for character as the edition appears on LinkedIn.
- `finding`, a sentence or two copied word for word from the issue.
- `package` and `repository`, if the hour uses one of my packages.
- `post`, the long version on mohammadi.cv, and `browser`, a page that runs the same check without installing anything. Both are optional.
- `commands`, the lines the hour starts from, each copied exactly from the issue.
- `source`, the issue's file in the newsletter's working folder, which the checks below read.

That working folder is private, so a fresh clone won't have it. When it is on the machine, `build.py` checks every entry against it: the number, date, title and link against the calendar's table of published issues, the finding and each command word for word against the issue, and every other link against the links the issue itself contains. An issue that hasn't gone out yet can't be listed. The folder is found at `--source`, else `$WL_SOURCE`, else `Weekend-Learning` next to this repository.

The page loads nothing from another site. It uses the system's own fonts, and `build.py` fails if anything on the page would load from elsewhere.
